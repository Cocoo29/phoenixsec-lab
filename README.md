# 🧠 PhoenixSec Lab — Cyberpunk Portfolio OS

> Cybersecurity & DevSecOps interactive portfolio built as a fake operating system interface.

![PhoenixSec OS Screenshot](./public/screenshot.png)

---

## 🚀 Project Overview

**PhoenixSec Lab** is an experimental cyberpunk-style portfolio built with **React + Vite**.  
The goal is to simulate a **fake operating system desktop environment** to showcase cybersecurity skills, projects, and technical profile in an interactive way.

This project is designed for **recruiters, technical interviews, and cybersecurity portfolio demonstration**.

---

## 🧩 Features

✔ Fake OS Boot Screen (TypeScript compilation simulation)  
✔ Secure Login Screen  
✔ Desktop UI with draggable windows  
✔ Cyberpunk Taskbar  
✔ Profile, Skills, Projects & Contact modules  
✔ Neon hacker UI & animations  
✔ GitHub Pages deployment  

---

## 🛠 Tech Stack

- **React 19**
- **Vite**
- JavaScript / JSX
- CSS (Cyberpunk UI)
- react-draggable
